# Unelma Laravel Backend

⚙️ **Unelma Platform Redesign – Backend**  
This repository contains the **backend** for the Unelma Platform redesign project, developed as part of **Software Development Team Project 2** at Business College Helsinki.  
Built with **Laravel**, it provides secure RESTful APIs, authentication, and database management for the React frontend.

---

## 📌 Features

-   RESTful API endpoints for frontend integration
-   Secure user authentication using **Laravel Sanctum**
-   Database migrations, seeders, and factories for testing
-   Input validation and error handling
-   Scalable backend architecture

---

## 🛠️ Tech Stack

-   **Backend:** Laravel 11
-   **Language:** PHP 8+
-   **Database:** MySQL
-   **Authentication:** Laravel Sanctum (JWT-based)
-   **API Testing:** Postman
